# Lalita Sahasranama: beginner demo (verses 1–5)

**Live demo:** <https://rackysu30.github.io/lalita-sahasranama-demo/> · **Recording guide:** <https://rackysu30.github.io/lalita-sahasranama-demo/recorder.html>

This is a **demo build** of a phone-first app for learning to recite the first 16 namas of the
Sri Lalita Sahasranama: listen, record yourself, compare, then rate your attempt. It works offline
once loaded and can be added to the home screen.

This repository contains only the built static site served by GitHub Pages. The source code and
project material live in a private repository.
